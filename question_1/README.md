# Question 1: R Package Development - Descriptive Statistics

### Package structure
```
descriptiveStats/
├── R/descriptiveStats.R   # R script with the six defined functions
├── man/                   # Manual directory - generated by Roxygen2
├── tests/                 # Passing tests for functions 
├── DESCRIPTION            # Additional required documents generated for a comprehensive package
├── LICENSE
├── LICENSE.md
└── NAMESPACE
```

---

### Functions
- calc_mean(x) - arithmetic mean
- calc_median(x) - median
- calc_mode(x) - mode
- calc_q1(x) - first quartile (Q1)
- calc_q3(x) - third quartile (Q3)
- calc_iqr(x) - interquartile range (IQR = Q3 - Q1)

Functions handle: empty vectors, non-numeric inputs, NA values, as well as handling ties and no mode cases for the calc_mode(x) function. 

### Example Usage

```r
# Install and load
devtools::install("question_1/descriptiveStats")
library(descriptiveStats)

devtools::test("question_1/descriptiveStats")    # Check tests   
devtools::check("question_1/descriptiveStats")   # Check package

# Example data
data <- c(1, 2, 2, 3, 4, 5, 5, 5, 6, 10)

# Use functions
calc_mean(data)    # 4.3
calc_median(data)  # 4.5
calc_mode(data)    # 5
calc_q1(data)      # 2.25
calc_q3(data)      # 5
calc_iqr(data)     # 2.75
```
